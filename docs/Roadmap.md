
1. Start company 1-2 weeks

  Technical 

    - setup company email (fastmail.com)
    - setup github organization 
    - setup company main communication tool discord/slack/zoom
    - setup domain and dns (cloudflare)
    - setup cloud account (hetzer/aws/gcloud)
    - setup github actions to deploy to dev/prod

  Team

    - stworzenie ofert pracy 
    - stworzenie procesu rekrutacji (
        - przykładowe pytania
        - kryteria i ocena kandydata
        - trening, mentoring i progresia zawodowa
    - advertise jobs (politechnika wrocławska/ uniwersytet w bydgoszczy)
    - rekrutacja
    
  Product
    
    - zrozumienie domeny problemu
    - napisanie one pager/pitch
    - design sprint[2] 
      - persona[1]
      - product roadmap
      - wirerames[3]
    - logo/branding
    - whitepaper?
    - analiza konkurecji na rynku
      - https://www.r3-trees.com/
      - https://planitgeo.com/treeplotter/
    - poszukiwanie róznych programów/grantów europejskich

  Firma

    - sprecyzowana umowa z współzałożycielami 
    - założenie spółki Zoo
    - Status/zarząd/księgowosć

  - import z shapefile do mapy
  - podstawowa tabela pokazująca dane na mapie
  - rózne kolory dla róznych typów (drzewa/trawnik)
  - wprowadznie nowych rekrutów
